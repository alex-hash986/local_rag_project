# Локальная ИИ-База Знаний (RAG-система) — MVP

Минимально жизнеспособный продукт (MVP) для персонального ИИ-ассистента, который позволяет загружать PDF-документы и задавать по ним вопросы в режиме чата. Проект работает на локальной архитектуре, автоматизирует анализ документов и рутину без слива данных в облачные CRM-системы.

## 🌟 Основные функции
- **Умный парсинг PDF:** Использование библиотеки `Docling` для быстрого извлечения текста и структуры таблиц (OCR отключен для максимальной скорости).
- **RAG-архитектура:** Построена на базе фреймворка `Haystack 2.0` с использованием локального хранилища `InMemoryDocumentStore`.
- **Интеллектуальные ответы:** Интеграция с OpenAI API для генерации точных ответов, основанных строго на контексте загруженных файлов.
- **Удобный веб-интерфейс:** Минималистичное интерактивное приложение на `Streamlit`.

## 🛠️ Стек технологий
- **Язык программирования:** Python 3.10+
- **RAG-движок:** Haystack 2.0
- **Парсер документов:** Docling (с параметром `do_ocr=False`)
- **Нейросетевая модель:** OpenAI API (модели GPT)
- **Интерфейс:** Streamlit

## 🚀 Инструкция по локальному запуску

### 1. Подготовка окружения
Убедись, что в корневой директории создан файл `.env` с твоим API-ключом:

```env
OPENAI_API_KEY=ваш_ключ_openai_сюда
```

### 2. Установка зависимостей
Выполни команду установки библиотек из корня твоего рабочего пространства (`pa-finance`):

```bash
pip install -r local_rag_project/requirements.txt
```

### 3. Запуск приложения
Запусти веб-интерфейс Streamlit из корня рабочего пространства:

```bash
python -m streamlit run local_rag_project/app.py
```

## 🎯 Целевая аудитория и польза
- **Для личной эффективности:** Быстрый поиск по личным архивам, книгам, учебникам и конспектам.
- **Для работы / Технических специалистов:** Мгновенный анализ тяжелых регламентов, технических инструкций, документации или длинных резюме кандидатов за пару секунд.
